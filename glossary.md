# Glossary

Short definitions to align terminology across docs and demos.

---

## Agent (Compute Agent)
Lightweight program that executes bounded, deterministic operators. See: [Compute Agent](/compute-agent)

## Orchestrator
Coordinates jobs and tasks across agents; validates results and handles retries. See: [Orchestrator](/orchestrator)

## Job
Large unit of work decomposed into tasks by the orchestrator.

## Task
Smallest schedulable unit; deterministic, idempotent, bounded in time/memory.

## Operator Set
Versioned set of deterministic primitives agents can execute. See: [Operator Set v1](/operator-set-v1)

## Trusted Agent
Registered/authenticated agent with reduced validation overhead; trust is revocable. See: [Trust & Validation](/trust-and-validation)

## Validation Receipt
Evidence generated by the orchestrator describing how a result was checked (method, rounds, outcome). See: [API Examples](/api-examples)

## Quarantine
Scheduling action that excludes an agent after validation failures until manual review or timeout.

## Capability Descriptor
Advertised properties of an agent (CPU, memory, operator sets, protocol version, optional trust signals). See: [Protocol](/protocol)

## Attestation
Optional mechanism to prove environment properties (e.g., TEEs); treated as advisory in early versions.

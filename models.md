# Models

## Purpose

This section hosts **fully open, reproducible pre-trained models** developed using this ecosystem.

Models are public artifacts, not proprietary assets.

---

### See also

- [Algorithms](/algorithms)
- [Architecture Overview](/architecture)

## Requirements

All models must:

- Be reproducible in principle  
- Publish full training configuration  
- Use permissive licenses  
- Be auditable

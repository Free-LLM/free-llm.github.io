# Contributing

## Who Can Contribute

Anyone.

Researchers, engineers, infrastructure operators, writers, and curious minds are all welcome.

---

## Ways to Contribute

- Research ideas  
- Code and infrastructure  
- Documentation  
- Running compute nodes  
- Reviews and discussions  

---

## Guidelines

- Open development  
- Public discussions  
- Respectful collaboration  
- Decisions justified with documentation  

---

## Getting Started

1. Explore the site  
2. Browse repositories  
3. Open an issue or PR  
4. Start small  

---

## Final Note

This project may fail — but it will fail **in the open**.
